# 🎓 EduSense AI

EduSense AI is an AI-powered learning assistant designed to help students understand and learn from their study materials.

## 🚀 Features

- 📄 Upload study materials
- 📝 Generate summaries
- ❓ Ask questions about study material
- 🧠 Generate quizzes
- 🎯 Personalized learning assistance

## 🛠️ Technologies

- Python
- Streamlit
- PyMuPDF
- AI / NLP
